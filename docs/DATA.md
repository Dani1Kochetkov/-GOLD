# Данные GOLD DAYZ: предметы, зомби, лут, карта

Всё лежит в `data/` и читается обычным JSON. После правки:

* на сервере — `/reload` (админ) или перезапуск;
* локально перед коммитом — `npm run check` (он ловит битые ссылки, пустые таблицы и превышение бюджетов пакетов).

Рядом лежат JSON-схемы (`data/schemas/*.schema.json`, подключены через `$schema`): редактор подсказывает поля и ловит опечатки ещё до запуска. Существование схем и их валидность тоже проверяет `npm run check`.

Формат проверяется тестами и `tools/check.js`: дубликаты id, неизвестные предметы в луте, нулевой урон, отсутствующие модели зомби и т.п. не пройдут.

## items.json

```json
{
  "id": "bandage",
  "name": "Бинт",
  "desc": "Останавливает небольшое кровотечение.",
  "slot": "none",
  "weight": 0.1,
  "stack": 10,
  "rarity": "common",
  "icon": "🩹",
  "usable": true,
  "heal": { "blood": 12, "time": 2500 }
}
```

| Поле | Обязательно | Значения |
|---|---|---|
| `id` | да | уникальный, латиница/`_` — попадает в команды и профили |
| `name`, `desc` | да | русский текст; **`desc` влияет на размер каталога** (2 байта на символ) |
| `icon` | желательно | emoji/символ для CEF |
| `slot` | да | `none`, `primary`, `melee`, `back`, `armor`, `mask`, `hands` |
| `weight` | да | кг на единицу; 0 для носимой экипировки |
| `stack` | да | максимум в одном слоте (1 = не стакается) |
| `rarity` | нет | `common`, `uncommon`, `rare`, `epic`, `legendary` (цвет рамки) |
| `equipable` | нет | можно надеть в `slot` |
| `storage` | нет | +N слотов (рюкзак/разгрузка) |
| `damageReduction` | нет | 0.15 = −15% входящего урона |
| `gasProtection` | нет | 0.8 = защита от токсинов |
| `radio` | нет | доступ к `/radio` |
| `weapon` | нет | блок оружия (см. ниже) |
| `heal` | нет | `{ blood, health, radiation, time }` |
| `food` | нет | `{ calories, water, time }` — `water` может быть отрицательным (консервы) |
| `reusable` | нет | предмет не расходуется (кружка) |
| `usable` | нет | кнопка «Использовать» |
| `unlocksMap` | нет | подсказка про карту |
| `ammo` | нет | это патроны |

Блок `weapon`:

```json
"weapon": {
  "hash": 453432689,          // GTA-хеш оружия (даёт модель, звук, анимацию)
  "damage": 28,               // урон на сервере
  "range": 35,                // метры
  "rate": 250,                // мс между выстрелами
  "ammoType": "ammo_9mm",     // null для холодного оружия
  "mag": 12,                  // размер магазина (0 для холодного)
  "noise": 110                // радиус шума для зомби, м
}
```

Правила:

* холодное оружие (`ammoType: null`) не тратит патроны и не шумит;
* огнестрел обязан ссылаться на существующий предмет с `"ammo": true`;
* хеши оружия — из GTA V (пистолет 453432689, дробовик 487013001, микро-ПП 324215364, карабин 2210333304, снайперка 100416529, нож 2578778090, бита 2508868239, лом 2227010557).

## loot.json

```json
"tables": {
  "medical": [
    { "item": "bandage", "weight": 18, "min": 1, "max": 4 }
  ]
}
```

* `weight` — относительная вероятность, не проценты (нормализуется автоматически).
* `min`/`max` — количество в одном «находке» (не больше `stack` предмета — иначе будет предупреждение).
* Таблицы: `civilian`, `medical`, `food`, `police`, `military`, `industrial`, `zombie_common`, `zombie_rare`.

Добавили новую таблицу — укажите её в `map.json` (`lootZones[].lootTable`) или в `zombies.json` (`lootTable`).

## zombies.json

```json
{
  "id": "runner",
  "model": "u_m_y_zombie_01",
  "health": 70,
  "speedWalk": 1.2,
  "speedRun": 3.4,
  "damage": 10,
  "attackRange": 1.6,
  "attackRate": 1100,
  "detectRange": 30,
  "chaseRange": 70,
  "score": 15,
  "lootTable": "zombie_common",
  "spawnWeight": 22
}
```

| Поле | Смысл |
|---|---|
| `char.health` | HP, урон оружия вычитается напрямую |
| `speedWalk` / `speedRun` | м/с в патруле и в погоне |
| `damage` / `attackRange` / `attackRate` | удар: урон, дистанция, мс между ударами |
| `detectRange` | с какого расстояния замечает |
| `chaseRange` | до какого расстояния продолжает погоню |
| `score` | очки за убийство |
| `lootTable` | что выпадает (шанс `loot.zombieLootChance`, по умолчанию 45%) |
| `spawnWeight` | относительная частота появления; 0 = только вручную |
| `onScream` | `{ radius, aggro, cooldown }` — крикун поднимает соседей |

Новый тип должен иметь `model`, существующий в вашей GTA (ванильные: `u_m_y_zombie_01`, `a_m_y_hippy_01`, `mp_m_waremech_01` и т.п.). Порядок в файле = `typeCode` в снапшотах.

## map.json

```json
{
  "spawnPoints": [ { "id": "sp_paleto_dock", "name": "…", "pos": { "x": -275, "y": 6635, "z": 32 } } ],
  "lootZones":   [ { "id": "lz_paleto_hospital", "name": "…", "pos": {…}, "radius": 35, "tier": 1, "lootTable": "medical", "count": 10 } ],
  "zombieZones": [ { "id": "zz_paleto", "name": "…", "pos": {…}, "radius": 190, "max": 22, "respawn": 26000 } ],
  "safeZones":   [ { "id": "sz_paleto_hub", "pos": {…}, "radius": 40, "pvp": false, "noZombies": true } ],
  "toxinZones":  [ { "id": "tz_lsia_depot", "pos": {…}, "radius": 35, "damagePerSecond": 6, "requiredItem": "gas_mask" } ]
}
```

* `lootZones[].count` — сколько находок держать в зоне; пополнение раз в `world.lootTopUpMs` (20 с) и только если игрок в 260 м.
* `tier` 1/2/3 — цвет круга на карте (гражданский/полиция/военный).
* `zombieZones[].max` — потолок на зону; глобальный потолок в `gold.config.json` → `world.zombieGlobalCap`.
* Сумма `max` больше глобального капа — предупреждение в `check` (часть зон не заполнится).
* Координаты — обычные координаты GTA V. Снять точку в игре: `/pos`.

## gold.config.json

Смысловые блоки:

| Блок | Что регулирует |
|---|---|
| `server` | шаг тика (100 мс), частота HUD, интервал сохранений, имя |
| `world` | PvP, капы зомби, время жизни лута, ночной множитель |
| `survival` | шансы кровотечения, синхронизация HP с движком |
| `spawn` | стартовый набор, дистанция от зомби, задержка респавна (`autoRespawn` — воскрешать ли без кнопки), неуязвимость |
| `zombies` | режим, интервалы спавна, дисперсия, радиус снапшота, деспавн |
| `loot` | радиусы подбора, лимит предметов на земле, шанс лута с зомби |
| `inventory` | вес, дроп при смерти, стартовый набор при респавне, кулдаун использования |
| `persistence` | включение и папка профилей |
| `access` | вайтлист: `whitelistEnabled`, `nicknames`, `socialClubIds`, `ips`, `kickMessage` |
| `admin` | включение, доступ только с localhost, список ников |
| `debug` | логи снапшотов, метрики, подсказки в чате |

Вход на сервер: отдельного логина и пароля нет — RAGE не поддерживает пароли, игрок заходит по нику.
Закрытый тест делается блоком `access`:

```json
"access": {
  "whitelistEnabled": true,
  "nicknames": ["ВашНик"],
  "socialClubIds": ["12345678"],
  "ips": ["10.0.0.5"],
  "kickMessage": "Сервер закрыт для теста."
}
```

Достаточно совпадения по любому списку. `whitelistEnabled: false` (по умолчанию) пускает всех.
Ник подделывается, Social Club ID — нет; для публичного сервера держите вайтлист выключенным.
Включённый вайтлист с пустыми списками закрывает сервер для всех — `npm run check` об этом предупредит.

Меняется на лету через `/reload` (кроме `server.tickMs` — шаг тика пересчитается после рестарта, а `metricsIntervalMs` применяется при старте).

## Частые ошибки

| Ошибка в консоли | Причина |
|---|---|
| `items.json: дубликат id "…"` | два предмета с одинаковым id |
| `map.json: зона "…" ссылается на неизвестную таблицу лута` | опечатка в `lootTable` |
| `loot.json: таблица "…" содержит неизвестный предмет` | предмет удалён/переименован, а лут остался |
| `каталог: часть N весит больше лимита` | слишком длинные `desc`/много предметов — сократите текст |
| `syntax error` в data | забытая запятая/кавычка — проверяйте JSON-валидатором |

Проверка одной командой:

```bash
npm run check
```
