## 2. Требует проверки в GTA (ручной прогон, ~30 минут)

Запустите сервер, подключитесь к `127.0.0.1:22005`.

### Вход и интерфейс

- [ ] Экран загрузки исчезает, HUD появляется (шкалы, часы, вес, счёт)
- [ ] `I` открывает инвентарь, курсор активен, игра не реагирует на мышь/движение
- [ ] `M` открывает карту, зоны читаемы, клик ставит метку, `Esc` закрывает
- [ ] Шрифты/контраст читаемы на 1920×1080 и 2560×1440
- [ ] Тосты не перекрывают прицел
- [ ] `F1` показывает телеметрию, значения осмысленные

### Зомби (главная цель проекта)

- [ ] Зомби появляются в Палето-Бей/Сэнди/Занкудо, не «падают с неба» на глазах
- [ ] Анимация шага выглядит естественно (не скольжение), нет T-позы
- [ ] Погоня: зомби ускоряются, не отстают на ровном месте и не телепортируются
- [ ] Удар: анимация + урон + виньетка, нет урона из-за спины на 5 м
- [ ] Смерть: рагдолл, труп исчезает, лут можно подобрать (`E`)
- [ ] Выстрел привлекает зомби в радиусе; нож — нет
- [ ] `F1`: `peds/ent` равны, snapshot ≤ 250 мс при 10–15 зомби
- [ ] Зомби не застревают в стенах/машинах надолго

### Инвентарь и бой

- [ ] Стартовый набор: нож, тряпки, газировка, карта
- [ ] Экипировка ножа/пистолета: модель в руках, GTA-анимация, звук выстрела
- [ ] Патроны в карточке оружия уменьшаются, `R` перезаряжает, пустой магазин не стреляет
- [ ] Drag & drop слотов работает, двойной клик экипирует/использует
- [ ] Бинт лечит кровотечение, консервы/вода восполняют шкалы
- [ ] Рюкзак добавляет слоты, снять его с полным верхом нельзя (понятная подсказка)
- [ ] Вес ограничивает подбор, сообщение объясняет причину
- [ ] GTA-радар/HUD скрыты, ничего не «двоится»

### Выживание и мир

- [ ] Голод/жажда падают за игровую сессию, не мгновенно и не «навсегда»
- [ ] Смерть от зомби: экран смерти с причиной и таймером, «Возродиться» работает
- [ ] После респавна камера/здоровье/инвентарь в порядке, вещи остались на месте смерти
- [ ] Ночь наступает по серверным часам, погода применяется
- [ ] Токсичная зона у LSIA: без противогаза плохо, с противогазом терпимо
- [ ] `/fill` у воды, `/pos`, `/stats` корректны

### Админка

- [ ] `/zcount` совпадает с видимым числом зомби
- [ ] `/zspawn 10` — появляются рядом, `/zclear` — исчезают
- [ ] `/tp`, `/tpway`, `/god`, `/heal`, `/setstat`, `/give` работают
- [ ] `/reload` подхватывает правку `data/items.json` без рестарта
- [ ] `/metrics` показывает адекватные цифры

### Стабильность

- [ ] 15 минут игры с зомби/лутом/смертями без падений клиента
- [ ] Лог сервера без ошибок (warn допустимы)
- [ ] Переподключение сохраняет профиль

## 4. Известные ограничения (осознанно)

| Ограничение | Влияние | План |
|---|---|---|
| Нет серверной трассировки карты | выстрел «сквозь стену» технически возможен | клиентский чек + серверный whitelist высот |
| Клиентские педы зомби | нет физики с машинами | серверные dynamic peds как альтернативный режим |
| Одна модель зомби | визуальная однотипность | набор моделей + `SET_PED_*` вариации |
| JSON-профили | не для тысяч игроков | SQLite/Postgres слой |
| Нет дельта-компрессии | трафик растёт с онлайном | бинарный протокол |
