# GOLD DAYZ — пошаговый гайд

**Локальный тест-сервер GTA 5 DayZ-мода на RAGE Multiplayer** с атмосферой хардкорного MTA DayZ c TOP-GTA.RU.

Стек (как вы и просили: **сервер — Node.js**, клиент — **JavaScript**, UI — **CEF HTML/CSS**, БД — **MySQL/MariaDB**):

| Слой | Технология | Где в проекте |
|---|---|---|
| Сервер | RAGE MP + **Node.js (JS)** | `packages/gold-dayz/` |
| Клиент | JavaScript (RAGE client) | `client_packages/gold-dayz/` |
| UI/HUD | CEF (HTML/CSS/JS) | `client_packages/gold-dayz/cef/` |
| БД | MySQL / MariaDB (mysql2) | `packages/gold-dayz/db/`, `sql/gold_dayz.sql` |

> Почему Node.js, а не C#: весь стек уже на JavaScript (клиент + CEF), RAGE MP сервер из коробки гоняет Node.js — один язык, один концептуальный слой, проще дебажить. C# подключать позже можно точечно (плагины в `dotnet/`), но для тестового сервера это лишнее.

---

## Что реализовано (6 обязательных механик)

1. **Классический HUD в CEF** — вертикальный столбец иконок справа: **Кровь ровно 12 000**, Еда, Вода, Температура, Шум, Видимость; при крови < 4000 экран уходит в **чёрно-белый** эффект (`timecycle 'blackNwhite'`), при смерти — экран смерти.
2. **Двухпанельный инвентарь на J** — слева лут с земли/из багажника, справа ваш рюкзак; вес 30 кг и лимиты слотов по категориям (оружие/патроны/инструменты/мед/еда/детали), экипировка стволов.
3. **Серверный спавн зомби через `mp.peds.new`** — только в стрим-зоне вокруг игрока, **лимит 25 (20–30) на игрока**; режимы **«Медленные зомби / светлая ночь»** и **«Быстрые зомби / тёмная ночь»** (`/zmode`); агро на **шум бега и выстрелы**.
4. **Хардкорная медицина и лут** — карта разбита на зоны (военные базы, больницы, города); **кровотечение → бинт**, **шок → обезболивающие**, **перелом ноги → ползание до морфина**.
5. **Сборка машин из деталей** — все машины спавнятся брошенными: без двигателя, без колёс, с пустым баком; нужны **Двигатель + Колёса + канистра бензина**.
6. **Апокалипсис-мод** — убран трафик, пешеходы-GTA и миникарта; подключено кастомное «заросшее» маппирование (образцы пропов + слот для YMAP/DLC).

## Шаг 1. Скачиваем и раскладываем структуру папок

1. Распакуйте архив **RAGE MP Server** в удобное место, например:
   ```
   C:\GOLD-DAYZ-SERVER\
   ```
   Внутри будут `ragemp-server.exe` (Windows) / `ragemp-server` (Linux), `conf.json`, папки `packages/`, `client_packages/`, `plugins/`, `dotnet/`.

2. **Скопируйте содержимое этого репозитория** поверх сервера (согласовывая папки):
   - `conf.json` → в корень сервера (заменить штатный);
   - `packages/gold-dayz/` → в `packages/`;
   - `client_packages/` → в `client_packages/` (туда же, с заменой).

   > ⚠️ **Удалите штатные примеры** из архива: `packages/freeroam/` (и другие примерные ресурсы), а также `client_packages/freeroam/`, если есть. RAGE грузит **каждую** папку в `packages/` как ресурс — чужой примерный код будет конфликтовать (спавн, телепорты, HUD).

3. Итоговая структура **должна получиться такой**:

   ```
   C:\GOLD-DAYZ-SERVER\
   ├─ ragemp-server.exe            ← бинарник сервера (из архива RAGE)
   ├─ conf.json                    ← НАШ конфиг (127.0.0.1, см. шаг 2)
   ├─ packages/                    ← серверный код (Node.js)
   │   └─ gold-dayz/
   │       ├─ index.js             ← точка входа ресурса
   │       ├─ package.json         ← зависимость mysql2
   │       ├─ config.js            ← ВСЕ настройки: БД, баланс, зоны, лут, машины
   │       ├─ sql/
   │       │   └─ gold_dayz.sql    ← схема БД (сервер прогонит её сам)
   │       ├─ db/
   │       │   └─ database.js      ← пул подключений MySQL
   │       └─ core/
   │           ├─ auth.js          ← /register, /login
   │           ├─ stats.js         ← кровь 12000, урон, смерть, сейвы
   │           ├─ inventory.js     ← вес/слоты, использование предметов
   │           ├─ loot.js          ← зоны лута: военные/больницы/города
   │           ├─ zombies.js       ← mp.peds.new, спавн в стрим-зоне, агро
   │           ├─ vehicles.js      ← сборка машин: двигатель/колёса/бензин
   │           └─ world.js         ← режимы ночи, погода, заросли LS
   ├─ client_packages/             ← клиентский код (JS + CEF)
   │   ├─ index.js                 ← require('./gold-dayz/index.js')
   │   └─ gold-dayz/
   │       ├─ index.js             ← подключает все модули
   │       └─ core/
   │           ├─ bus.js           ← внутренняя шина событий клиента
   │           ├─ hud.js           ← CEF HUD + ч/б эффект низкой крови
   │           ├─ medical.js       ← перелом → ползание
   │           ├─ inventory.js     ← клавиши J/E/ESC, работа с CEF
   │           ├─ vehicles.js      ← визуал разбитости, блокировка мотора
   │           ├─ zombies.js       ← ИИ зомби на клиенте-владельце, шум
   │           └─ world.js         ← удаление трафика/миникарты
   │       └─ cef/
   │           ├─ hud/             ← index.html + style.css + script.js
   │           └─ inventory/       ← index.html + style.css + script.js
   ├─ maps/                        ← ваши JSON-карты (RAGE формат)
   ├─ plugins/                     ← .dll плагины (голос и т.п.)
   └─ dotnet/                      ← C# (отключён в conf)
   ```

> **Право клиента:** все `require(...)` в `client_packages` считаются **от корня `client_packages`** (поэтому везде написано `require('./gold-dayz/core/...')`, а не `require('./core/...')`). Серверные require — обычные, относительно файла.

## Шаг 2. Настраиваем `conf.json` под 127.0.0.1

Наш `conf.json` уже лежит в корне. Ключевые поля:

```json
{
  "announce": false,        // не светить сервер в публичный список (локальный тест)
  "bind": "127.0.0.1",      // слушать только локалку — безопасности ради
  "gamemode": "gold-dayz",  // имя ресурса в packages/ (у нас packages/gold-dayz)
  "maxplayers": 50,
  "name": "GOLD DAYZ [LOCAL TEST]",
  "language": "ru",
  "port": 22005,            // UDP+TCP игровой порт; 22006 = HTTP для скачивания пакетов
  "stream-distance": 400.0, // дистанция стрима (плоскость X,Y)
  "sync-rate": 40,          // герцы синхронизации
  "enable-nodejs": true,    // ОБЯЗАТЕЛЬНО: наш серверный код на Node.js
  "allow-cef-debugging": true, // F12 в CEF — очень удобно при отладке UI
  "voice-chat": false,      // голос не нужен для теста
  "disallow-multiple-connections-per-ip": false // несколько клиентов с одного ПК
}
```

Что помнить:

- **`bind: 127.0.0.1`** — подключиться сможет только эта машина. Для друзей по сети замените на `0.0.0.0` и откройте порты `22005/tcp+udp` и `22006/tcp` в фаерволе.
- Шифрование RAGE в 1.1+ **всегда включено**, поле `encryption` устарело — не добавляйте его.
- Порт `22006` должен быть свободен — на нём RAGE поднимает HTTP-сервер отдачи `client_packages` (именно поэтому клиент сам скачает наши CEF/JS файлы).

## Шаг 3. Создаём базу MySQL

1. Запустите MySQL/MariaDB и создайте базу:
   ```sql
   CREATE DATABASE gold_dayz CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```
2. Откройте `packages/gold-dayz/config.js` и впишите доступы:
   ```js
   const db = {
     host: '127.0.0.1',
     port: 3306,
     user: 'root',
     password: 'password',   // ← ваш пароль
     database: 'gold_dayz',
     charset: 'utf8mb4'
   };
   ```
3. Импорт схемы **делать не обязательно**: при старте сервер сам прогонит `sql/gold_dayz.sql` (таблицы `accounts`, `characters`, `vehicles`).

> Без работающей БД сервер **всё равно запустится** (режим «только память»), просто прогресс не сохранится. В консоли будет жёлтая ошибка — это сигнал настроить доступы.

## Шаг 5. Запуск сервера и вход в игру

1. Запустите `ragemp-server.exe`. В консоли ищите:
   ```
   [GOLD] MySQL подключена: gold_dayz (ok)
   [GOLD] Лут разложен: N предметов в 6 зонах
   [GOLD] Зомби-менеджер запущен: модель u_m_y_zombie_01, лимит 25/игрок
   [GOLD] Все модули запущены. Режим ночи: slow
   ```
2. Запустите **RAGE Multiplayer** (клиент), в лаунчере введите адрес `127.0.0.1` и нажмите Connect (или `connect 127.0.0.1` в консоли клавишей F10 в лаунчере).
3. Вы заспавнились **сразу** — можно тестировать. Чтобы прогресс сохранялся, зарегистрируйтесь в чате:
   ```
   /register player password123
   /login player password123
   ```

### Команды

| Команда | Что делает |
|---|---|
| `/register <логин> <пароль>` | создать аккаунт + персонажа (вход сразу) |
| `/login <логин> <пароль>` | загрузить сохранённого персонажа |
| `/zmode slow` | **Медленные зомби / светлая ночь** (21:30, спокойно) |
| `/zmode fast` | **Быстрые зомби / тёмная ночь** (02:00, зомби бегают) |
| `/pos` | вывести координаты (для расстановки лута/машин/карты) |

### Управление

| Клавиша | Действие |
|---|---|
| **J** | открыть/закрыть инвентарь (две панели) |
| **E** | открыть инвентарь с авто-вкладкой: рядом машина → багажник, иначе земля |
| **ESC** | закрыть инвентарь |
| ЛКМ по кнопкам в CEF | Взять / Использовать / Выбросить / Установить детали / Заправить / Завести |

## Шаг 6. Как работают механики (карта кода)

### 1) HUD и чёрно-белый экран
- Сервер: `core/stats.js` — тик в 1 сек, единый пакет `hud:stats` (кровь/еда/вода/температура/шум/видимость/кровотечение/шок/перелом/ночь/машинa).
- Клиент: `core/hud.js` — шлёт JSON в CEF (`browser.call('updateStats', ...)`) и крутит **`setTransitionTimecycleModifier('blackNwhite')`** с силой, растущей по мере потери крови (< 4000 ед.).
- CEF: `cef/hud/` — столбец иконок **справа**, кровь жёстко `blood / 12000`, тирность цвета как в MTA (>60% зелёный, >30% оранжевый, иначе красный), оверлеи ночи/шока/смерти.

### 2) Инвентарь на J
- Клиент `core/inventory.js` ловит J/E/ESC, открывает CEF-браузер, курсор (`mp.gui.cursor.show`).
- Сервер `core/inventory.js`: валидация веса (30 кг) и слотов, стаки, `inv:action` (take/drop/use/toVehicle/fromVehicle).
- CEF `cef/inventory/` — **левая панель**: вкладки «НА ЗЕМЛЕ»/«МАШИНА», **правая**: рюкзак + чипы слотов + кнопки действий.

### 3) Зомби (`mp.peds.new`)
- Сервер `core/zombies.js`:
  - тик 3 сек: кольцо спавна **45–130 м** вокруг игрока, не больше **25 живых в радиусе**, деспавн дальше 170 м;
  - для точного Z грунта сервер шлёт клиенту `zombie:groundZ`, клиент отвечает `zombie:spawnResult` (шейп-тест);
  - тик 1 сек: агро = база режима + `шум игрока × 0.45` + пульс выстрела (+55 на 8 сек); укус в 1.7 м = **220 крови**, шанс кровотечения 30%, шанс перелома 8%;
  - переменные `ownerId`/`aggro`/`speed` синхронизируются на клиенты.
- Клиент `core/zombies.js`: **владелец зомби** (клиент ближайшего игрока) крутит ИИ: `taskWanderStandard` без цели, `combatPed`/`taskFollowNavMeshToCoord` в агро; в режиме `fast` каждый кадр крутится `SET_PED_MOVE_RATE_OVERRIDE = 1.65` (бег), в `slow` — `0.6` (шаг). Шум от бега/выстрелов репортится на сервер (`hud:clientStats`, `noise:shot`).

### 4) Хардкорная медицина
- `core/stats.js` (`applyDamage`): укусы/падения крутят статусы; кровотечение теряет **2.5×уровень крови/сек**, голод/жажда при 0 — минус кровь/сек, реген каждые 5 сек только если еда>50, вода>50 и нет кровотечения.
- Лечится **только предметами**: бинт (кровотечение), обезболивающее (шок −50), морфин (снимает перелом).
- Зоны лута: `config.js → lootZones` (Форт-Занкудо, Больница, Грув, Легион, Сэнди, Палето) и весовые таблицы `lootTables`.

### 5) Сборка машин
- `core/vehicles.js`: при спавне у машины `hasEngine=false, hasWheels=false, fuel=0`; клиент рвёт колёса (`setTyreBurst`) и убивает мотор (`setEngineHealth -4000`).
- Из инвентаря (вкладка «МАШИНА»): «Установить двигатель» (нужен предмет `engine`), «Установить колёса» (предмет `wheels`), «Заправить» (канистра = +20 л), «Завести» — только с водительского места и при выполненных условиях. Бензин горит 0.08 л/сек, на нуле мотор глохнет.

### 6) Апокалипсис
- Клиент `core/world.js`, **каждый кадр**: `setPedDensityMultiplierThisFrame(0)`, `setVehicle/Parked/RandomDensityMultiplierThisFrame(0)`, нативы-бюджеты популяции = 0, **`mp.game.ui.displayRadar(false)`** (миникарты нет), wanted level = 0, nametags выключены.
- `core/world.js` (сервер) спавнит пропы-заросли (`mp.objects.new`) — ваши модели/координаты там же.
- **Ваша карта**: положите YMAP/DLC в `client_packages/game_resources/dlcpacks/<ваш_pak>/common/data/levels/gta5/` — RAGE подхватит при старте клиента. Точки спавна лута/машин/зомби — правьте в `config.js`.

## Шаг 7. Типовые проблемы

| Симптом | Решение |
|---|---|
| Клиент не подключается к 127.0.0.1 | Сервер запущен? Порт 22005 не занят? В консоли сервера нет ошибок `conf.json`? |
| Ошибка `Cannot find module 'mysql2'` | Забыли `npm install` **внутри** `packages/gold-dayz` |
| `[GOLD][ОШИБКА] Не удалось подключиться к MySQL` | Проверьте `config.js → db` и `CREATE DATABASE gold_dayz ...` |
| HUD/инвентарь не появляются | `allow-cef-debugging: true` → F12 в игре, вкладка Console; проверьте, что путь `package://gold-dayz/cef/...` существует |
| Пусто на карте: нет лута/машин/зомби | Смотрите консоль сервера: там ошибки моделей/координат; лут респавнится 8 мин |
| Зомби стоят как статуи | ИИ крутит клиент-**владелец**: нужен второй игрок или подождите переназначения; убедитесь, что модель `u_m_y_zombie_01` существует (в консоли нет ошибки) |
| Нет машинного трафика, миникарты | Это **нормально** — требование №6 |
| Другие ресурсы в `packages/` больше не грузятся | RAGE грузит каждую папку как ресурс; конфликт имен/ошибки в чужом `index.js` смотрите в консоли |

## Шаг 8. Куда развивать дальше (по приоритетам)

1. **Логин-CEF вместо чата** — окно в стиле TOP-GTA с фоном и слоями.
2. **Серверный тик урона зомби от ударов** уже есть (проксимити); добавьте `taskMelee` анимации ударов (`taskPlayAnim` c `melee@...`) для понтов.
3. **Холод/погода**: в `config.js` заложены `TEMP_*`; подключите `mp.world.weather = 'XMAS'|'THUNDER'` и костры-заправки температуры.
4. **Контейнеры/двери**: колшейпы (`mp.colshapes.newSphere`) на точки лута вместо засорения инвентаря.
5. **Античит-глубина**: сейчас дистанция взятия перепроверяется сервером (`loot.js → take`), урон зомби — серверный; HP-патч (`player.health=100`) — осознанная механика DayZ.
6. **Голос/3D** — отключён в conf; включите `voice-chat` и подключите плагин голоса в `plugins/`.
