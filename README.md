# GOLD DAYZ — RAGE Multiplayer dev server

Локальный каркас GTA V DayZ для **RAGE Multiplayer**: серверная проверка попаданий по заражённым, клиентские локальные модели NPC, серверный инвентарь с JSON-сохранением и стартовая зона в Sandy Shores. Конфигурация из коробки слушает только `127.0.0.1` — публичные подключения закрыты.

> В репозитории находятся игровые ресурсы и конфигурация, но не бинарники RAGE MP и не GTA V. Серверные файлы RAGE MP нужно получить из официального источника и установить отдельно. Не запускайте серверный исполняемый файл, скачанный с неизвестного сайта.

## Быстрый запуск на Windows

1. Установите GTA V и RAGE Multiplayer на ПК, затем получите **официальные серверные файлы RAGE MP**.
2. Распакуйте серверный дистрибутив в корень этого проекта, рядом с `conf.json`; в корне должен появиться `ragemp-server.exe`. Не заменяйте файлы проекта одноимёнными файлами из дистрибутива без проверки.
3. Запустите `start-local.bat`.
4. В клиенте RAGE MP подключитесь к `127.0.0.1:22005`.

Для Linux используйте официальный Linux server runtime в корне проекта и выполните `./start-local.sh`. Node.js на хост-машине нужен только для запуска unit-тестов, не для игрового сервера: скрипты ресурса исполняются встроенным Node.js RAGE MP.

## Что уже работает

- Имя `GOLD DAYZ`, локальный bind `127.0.0.1`, порт `22005`, лимит 32 игрока; анонсирование и voice chat выключены (`conf.json`).
- Спавн тестового персонажа в Sandy Shores и команды `/help`, `/inv`, `/zombies`, `/pos`.
- Директор заражённых создаёт до 18 серверных записей. Клиент запрашивает общий снимок и отображает NPC; нажатие **E** вблизи отправляет запрос удара. Сервер проверяет расстояние, cooldown, ID и здоровье; смерть и награда применяются сервером.
- Инвентарь (вода, консервы, бинты) ведётся сервером; награда за уничтоженного заражённого — одна консерва. Состояние сохраняется в `packages/gold-dayz/data/players.json` с атомарной заменой файла.
- Настройки спавна и заражённых находятся в `shared/settings.json`.

Это стартовый прототип механик, а не готовый публичный DayZ-мод: сейчас зомби стоят на месте, их NPC-представления локальны для каждого клиента, нет полноценного лута/крафта, аккаунтов, античита, UI-инвентаря и продуманной миграции данных. Ключ игрока для сохранения — Social Club, с именем как запасным вариантом; для публичного сервера нужна настоящая авторизация и уникальный стабильный account ID.

## Проверка логики

Из корня проекта, с установленным Node.js 18 или новее:

```sh
npm test
```

Тесты проверяют лимиты инвентаря, жизненный цикл заражённого и расчёт расстояния. Они не заменяют запуск игрового клиента: после установки сервера проверьте также вход двух клиентов и синхронность урона/награды.

## Настройка и перенос на VDS

- Локальная разработка на этом же ПК: оставьте `bind` как `127.0.0.1`.
- Проверка по домашней LAN: смените `bind` на `0.0.0.0` и откройте нужный порт в локальном firewall; подключайтесь к LAN-IP хоста.
- Для публичного VDS сначала перенесите официальный серверный runtime и проект, задайте `bind: "0.0.0.0"`, смените имя/лимит по необходимости и настройте firewall/security group по актуальной документации RAGE MP и провайдера. Не включайте анонсирование до настройки и проверки сервера.
- Перед публичным запуском добавьте аккаунтную авторизацию, валидацию всех сетевых событий, резервное копирование данных, ротацию логов и контроль ресурсов. Не переносите локальный JSON как надёжную базу для конкурентных записей; для роста мигрируйте на БД.
- Не публикуйте серверный порт и не открывайте bind наружу, пока прототип не прошёл проверку безопасности. Не храните бинарники сервера, GTA V файлы или персональные данные в Git.

## Структура

```text
conf.json                         RAGE MP config (локальный bind)
packages/gold-dayz/src/            серверная логика
client_packages/gold-dayz/         клиентский код NPC и управления
shared/settings.json               настройки спавна и механик
start-local.bat / start-local.sh    локальный запуск после установки runtime
test/                              unit-тесты чистой игровой логики
```
