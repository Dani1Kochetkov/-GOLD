# GOLD DAYZ для MTA:SA

Самостоятельная сборка DayZ-выживания для **Multi Theft Auto: San Andreas** (GTA San Andreas):
зомби и мутанты, голод/жажда/кровь/радиация, лут, крафт, торговцы, базы с PIN-складом,
пост-апокалиптический транспорт и PvP. Всё написано с нуля на Lua + CEF (HTML/CSS/JS).

> Это не копия MTA DayZ: NON-STOP и не файлы чужого сервера. Код, интерфейс, данные и
> баланс — оригинальные. Используются только стандартные модели и оружие GTA: SA,
> которые поставляются вместе с клиентом MTA. Названия чужих сборок не используются.

## Требования

* **MTA:SA Server 1.6.0+** (Windows или Linux) и клиент **MTA:SA 1.6+**.
* Никаких сторонних ресурсов, библиотек и баз данных: SQLite встроен в MTA.
* Клиентский браузер CEF — стандартная часть MTA (используется для интерфейса).

Ресурс не требует прав ACL для обычной работы. Для админ-команд нужен доступ
к `command.admin` (группа Admin) — см. [docs/ADMIN.md](docs/ADMIN.md).

## Установка

1. Скачайте и распакуйте **MTA:SA Server** с [mtasa.com](https://mtasa.com) (или возьмите
   уже работающий сервер).
2. Скопируйте папку `gold_dayz` целиком в:

   ```text
   <сервер>/mods/deathmatch/resources/gold_dayz/
   ```

   Внутри должны оказаться `meta.xml`, `shared/`, `server/`, `client/`, `data/`, `ui/`.
3. В консоли сервера (или через админ-панель):

   ```text
   refresh
   start gold_dayz
   ```

4. Запустите клиент, подключитесь к серверу и зарегистрируйтесь в окне входа.
5. Если что-то не так: в клиенте `debugscript 3`, в консоли сервера — `debug 3`.

При первом запуске рядом с `meta.xml` появится `gold_dayz.db` — это и есть сохранения.
Удалите файл, чтобы начать с чистого сервера (аккаунты, профили, склады).

### Проверка установки

В консоли сервера после `start gold_dayz` должно появиться примерно:

```text
[GOLD DAYZ] SQLite: gold_dayz.db
[GOLD DAYZ] data: 56 предметов, 10 таблиц лута, 5 типов зомби, 16 лут-зон, 15 зон зомби
[GOLD DAYZ] GOLD DAYZ 1.0.0 — запуск
[GOLD DAYZ] базы: 4
[GOLD DAYZ] торговцы: 4
[GOLD DAYZ] транспорт: 10
[GOLD DAYZ] лут: ... предметов в 16 зонах
[GOLD DAYZ] зомби: стартовое заполнение ...
[GOLD DAYZ] готово: предметов 56, зон 16, зомби ..., машин 10, баз 4
```

## Управление

| Клавиша | Действие |
|---|---|
| `E` | подобрать лут / обыскать тело / торговать / убежище |
| `I` | инвентарь |
| `M` | карта зон |
| `C` | крафт |
| `F1` | помощь |
| `Esc` | закрыть панель |
| `T` | чат (стандартный) |

Резервный вход без CEF — команды в чате:

```text
/dzreg логин пароль     — регистрация
/dzlogin логин пароль   — вход
/dzplay                 — спавн со случайной точки
/dayz                   — подсказка
```

## Как играть

1. **Зарегистрируйтесь и выберите точку спавна.** Стартовый набор: 2 тряпки, газировка,
   нож и карта. Деньги — $500.
2. **Соберите лут в гражданских зонах** (магазины, больницы, заправки). Чем выше tier зоны,
   тем лучше оружие, но тем больше зомби и агрессивнее боссы.
3. **Следите за шкалами.** Голод и жажда падают постоянно; кровь восстанавливается только
   без кровотечения; в радиации нужен противогаз; ночью и в воде падает температура.
4. **Торгуйте в лагерях.** Торговцы покупают ценности и лишний лут, продают медицину,
   патроны и снаряжение. Запас пополняется раз в 10 минут.
5. **Крафтите на базе или в лагере.** Бинты из тряпок, ремкомплект из металлолома и скотча,
   броня и рюкзак — обязательные вещи для дальних вылазок.
6. **Займите убежище.** Склад защищён PIN-кодом, внутри действует безопасная зона:
   можно передохнуть, сложить лут и переждать ночь.
7. **Прокачивайте транспорт.** Топливо кончается, двигатель глохнет без него; канистра
   заправляет, ремкомплект чинит кузов.
8. **Не умирайте с полным рюкзаком.** После смерти вещи остаются в трупе на 10 минут —
   их можно вернуть, если добежать первым.

### Зомби

| Тип | HP | Скорость | Урон | Особенность |
|---|---:|---:|---:|---|
| Ходячий | 90 | 2.2 | 9 | обычный житель пустоши |
| Бегун | 70 | 5.2 | 12 | быстрый, но хрупкий |
| Громила | 300 | 2.9 | 27 | выдерживает очередь |
| Охотник | 520 | 4.6 | 22 | мутант, догоняет |
| Исполин (босс) | 1600 | 2.6 | 42 | 4–6 предметов топ-лута |

Зомби слышат выстрелы (радиус зависит от оружия: пистолет ~80 м, винтовка ~130 м) и
шаги. В безопасной зоне и на спавне они не атакуют. Босс появляется в своей зоне при
наличии игроков и возрождается через 15 минут.

## Данные и настройка

Все игровые данные лежат в `gold_dayz/data/*.json` и читаются сервером при старте:

| Файл | Что меняется |
|---|---|
| `items.json` | предметы: вес, стак, редкость, урон/эффект, иконка-эмодзи, цена |
| `loot.json` | таблицы лута: предмет, вес выпадения, min/max количество |
| `zombies.json` | типы зомби: HP, скорость, урон, радиусы, скины, лут-таблица |
| `map.json` | точки спавна, лут- и зомби-зоны, лагеря, радиация, базы, время/погода/туман |
| `traders.json` | торговцы: позиция, скин, ассортимент, цены, запас |
| `vehicles.json` | точки спавна машин и списки моделей (400–611) |
| `recipes.json` | рецепты крафта: результат, ингредиенты, нужен ли верстак |
| `config.json` | тайминги, лимиты, экономика, включение PvP/баз/торговцев |

После правки: `/dzreloaddata` (права админа) или перезапуск ресурса. Перезагрузка данных
не пересоздаёт уже заспавненных зомби/лут — для полного применения нужен `restart gold_dayz`.

Подробная админка и тюнинг: [docs/ADMIN.md](docs/ADMIN.md).
Устройство кода и тесты: [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Тесты

Тесты не требуют MTA и GTA — только Node.js 18+:

```bash
cd mta
npm install
npm run verify
```

Или вручную:

```bash
node tools/luacheck.js    # JSON, синтаксис Lua, meta.xml, UI, 98 тестов shared-логики
node tools/simulate.js    # 92 шага серверного сценария на mock-MTA
node tools/ui-smoke.js    # 21 проверка CEF-интерфейса в jsdom (нужен npm install)
```

Интерфейс можно посмотреть без MTA: откройте `gold_dayz/ui/index.html` в браузере — включится
демо-режим с образцами экранов (вход, персонаж, инвентарь, торговля, база, крафт, карта,
смерть). Вход и выбор точки спавна в демо работают по-настоящему (локальный макет вместо
сервера), панель сверху переключает сцены. В MTA этот режим не активируется.

`ui-smoke.js` загружает ту же страницу в jsdom и проверяет, что все девять демо-экранов
отрисовываются, Esc закрывает панель, вход и спавн отправляют корректные пакеты в
`mta.triggerEvent("dz:ui", ...)`, а битый JSON не роняет интерфейс.

`simulate.js` поднимает fengari (Lua в Node), подсовывает минимальный MTA-API и проигрывает
полный путь: старт ресурса → вход → спавн → экипировка → зомби → лут → торговец → крафт →
база и PIN → транспорт → смерть → возрождение → админ-команды → сохранение и перезаход.

## Ограничения (честно)

* **Нет серверной коллизии мира.** Сервер MTA не умеет `getGroundPosition`; зомби и лут
  стоят на высотах из `map.json`, поэтому на сложном рельефе возможны «висящие» или
  утопленные модели. Лечится ручной подгонкой `z` в зонах.
* **Зомби не обходят препятствия.** ИИ идёт по прямой, клиент интерполирует позицию;
  педы могут проходить сквозь стены и заборы. Это осознанный компромисс ради
  производительности и синхронизации.
* **Зомби — клиентские педы.** Каждый клиент создаёт их локально, урон присылает клиент,
  сервер проверяет дистанцию, оружие и rate-limit. Это не античит уровня банка, но
  исключает «убийство через всю карту».
* **Стрельба и оружие — нативные GTA.** Баллистика, отдача и модели — стандартные;
  урон по зомби пересчитывается сервером по своей таблице.
* **SQLite, один сервер.** Для сети из нескольких серверов нужен MySQL-адаптер
  (точка расширения — `server/db.lua`).
* **Нет клановых войн, carwars, сезонных ивентов и лаунчера.** Это дорожная карта, а не
  готовые функции; база для них (базы, PvP, транспорт, сохранения) уже есть.
* **Баланс — стартовый.** Числа в `config.json` и `shared/core.lua` подобраны для игры
  на 20–50 человек; под свой сервер их стоит прогнать через `simulate` и живые тесты.
* **Только оригинальные ассеты.** Кастомные модели, текстуры, звуки и карты не входят;
  используются стандартные скины/оружие GTA: SA. Замена описана в docs/DEVELOPMENT.md.

## Дорожная карта

1. Кланы: создание, тег, клановый чат, войны за зоны, carwars.
2. Сезонные ивенты: волны, карантин, воздушные сбросы, ночные боссы.
3. MySQL + панель статистики.
4. Кастомные модели зомби/одежды и звуки (после проверки прав).
5. Больше карт и интерьеров, подземелья, метро.
6. Расширенный античит-слой (проверка анимаций, телепортов, скорости).

## Лицензия

Внутренний проект (`UNLICENSED`). GTA: San Andreas, MTA:SA и их файлы принадлежат
соответствующим правообладателям; серверные файлы MTA и игровые ассеты здесь не
распространяются. Сторонние сборки (включая MTA DayZ: NON-STOP) не использовались:
совпадения механик объясняются общим жанром.
