# GOLD DAYZ · администрирование и тюнинг

## 1. Права доступа

Команды `/dz*` доступны, если выполнено хотя бы одно условие:

* у игрока есть ACL-право `command.admin` (обычно группа **Admin**);
* у игрока есть право `function.kickPlayer`;
* его **аккаунт** (логин, не игровой ник) указан в `data/config.json`:

```json
"admin": { "accounts": ["owner", "moderator"] }
```

Проверка выполняется на сервере. Обычный игрок получает только тост «Недостаточно прав».

Рекомендуемая настройка: создать ACL-группу `GoldAdmin`, выдать ей `command.admin`,
добавить туда доверенных игроков и не хранить список в JSON, если сервер публичный.

## 2. Команды

| Команда | Аргументы | Что делает |
|---|---|---|
| `/dzhelp` | — | список команд |
| `/dzgive` | `[ник] <itemId> [кол-во]` | выдать предмет себе (если первый аргумент — id предмета) или игроку |
| `/dzmoney` | `[ник] <сумма>` | начислить/списать деньги (можно отрицательное) |
| `/dzheal` | `[ник]` | полное лечение: HP, кровь, голод, жажда, температура, кровотечение, инфекция, радиация |
| `/dzarmor` | `[ник]` | выдать тяжёлый бронежилет предметом |
| `/dzstats` | — | онлайн, зомби, лут, машины, аккаунт, позиция |
| `/dzfree` | — | принудительный респавн (без потери инвентаря на месте — инвентарь сохраняется) |
| `/dzspawn` | `<x> <y> [z]` | телепорт |
| `/dzspawnzombies` | `[попытки 1–10]` | несколько тиков спавна зомби рядом |
| `/dzcars` | — | список машин в мире |
| `/dzsettime` | `<0–23> [0–59]` | время сервера |
| `/dzsetweather` | `<0–255>` | погода |
| `/dzsave` | — | сохранить все профили и склады баз |
| `/dzreloaddata` | — | перечитать `data/*.json` без рестарта |
| `/dzkick` | `<ник> [причина]` | кик с сохранением профиля |

Примеры:

```text
/dzgive bandage 10
/dzgive Ivan ak47 1
/dzmoney 5000
/dzmoney Ivan -300
/dzsettime 22 30
/dzsetweather 11
```

`/dzfree` не «убивает» игрока: он просто переносит его на точку спавна с полным лечением.
Если нужен именно чистый респавн с потерей вещей — используйте игровое самоубийство в
экране помощи.

сервера и клиента, поэтому меняются только рестартом ресурса.

## 4. База данных

* Файл: `gold_dayz/gold_dayz.db` (SQLite, создаётся автоматически).
* Таблицы:
  * `accounts(name, salt, hash, created)` — логин, соль, sha256-хеш (400 итераций);
  * `players(name, data, updated)` — JSON-профиль;
  * `bases(id, owner, code, stash, updated)` — владелец, PIN, JSON склада.

Резервная копия — просто копия файла при остановленном ресурсе:

```bash
stop gold_dayz
cp mods/deathmatch/resources/gold_dayz/gold_dayz.db /backup/gold-$(date +%F).db
start gold_dayz
```

Восстановление: положить файл обратно, запустить ресурс. Сброс: остановить ресурс,
удалить `gold_dayz.db`, запустить (все аккаунты и склады пропадут).

Рекомендуется ежедневный бэкап по cron и хранение 7–14 копий. Для публичного сервера
с большим онлайном SQLite может стать узким местом на автосохранениях раз в 90 секунд —
в этом случае переходите на MySQL (см. docs/DEVELOPMENT.md, раздел «Расширение БД»).

## 5. Производительность

Ориентиры для VDS 2 vCPU / 2 ГБ:

* 20–30 игроков: стандартные настройки, `tickMs=250`, `snapshotMs=200`.
* 40–60 игроков: `zombies.globalCap=70`, `perPlayerCap` не выше 25,
  `loot.groundCap=300`, `snapshotMs=250`, `hudMs=750`.
* Если сервер «лагает» на спавне: уменьшите `initialFill` до 0.35 и `max` в зонах.

Что дороже всего: тик зомби (O(n²) расталкивания при 90 зомби — около 4 000 пар за тик),
снапшоты (JSON на каждого игрока 5 раз в секунду) и HUD (2 раза в секунду). Уменьшайте
сначала количество зомби, потом частоту снапшотов.

Логи: `outputServerLog` пишет немного, но `outputDebugString` в `admin.lua` — по одной
строке на команду при старте. Для тишины уберите эти строки или `config.logging=false`
(отключает только `[GOLD DAYZ]`-логи, не ошибки MTA).

## 6. Безопасность

* Не публикуйте `gold_dayz.db` через веб-сервер MTA: файлы базы не перечислены в
  `meta.xml`, поэтому клиентам не скачиваются, но HTTP-доступ к папке ресурса может
  отдавать статику — проверьте настройки веб-порта.
* Смените пароль `admin` в ACL MTA и закройте консоль сервера.
* Включите штатный античит MTA (`<settings>` в `mtaserver.conf`, `ase` отключить,
  если не нужен сервер в списке).
* Ставьте `pvp=false` на время ивентов/тестов, если нужен мирный сервер.
* PIN базы — не пароль: 3–8 цифр подбираются. Для публичного сервера ограничьте
  число попыток (сейчас ограничения нет — это точка роста) или используйте длинные PIN.
* Rate-limit уже есть: 10 UI-действий/с, 12 ударов по зомби/с, 10 шумовых событий/с,
  проверка дистанции и оружия на сервере.
