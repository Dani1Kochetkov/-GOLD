# GOLD DAYZ · чек-лист приёмки в игре

Автотесты проверяют логику без MTA, но внешний вид и «ощущения» — только в игре.
Этот список проходится за 20–30 минут на локальном сервере.

## Запуск

- [ ] `refresh` + `start gold_dayz` без красных ошибок в консоли.
- [ ] В логе есть `готово: предметов 56, зон 16, зомби …, машин 10, баз 4`.
- [ ] Клиент `debugscript 3` — нет ошибок Lua после входа.
- [ ] На сервере рядом с `meta.xml` появился `gold_dayz.db`.
- [ ] Клавиша `F1`/`I`/`M`/`C` открывает панели, `Esc` закрывает.
- [ ] Курсор появляется только при открытом интерфейсе; персонаж не стреляет по UI.

## Вход и персонаж

- [ ] Экран входа: виден сервер, версия, кнопка регистрации.
- [ ] Регистрация нового ника, пароль < 4 символов — понятная ошибка.
- [ ] Повторный вход с тем же ником восстанавливает деньги/вещи/счётчики.
- [ ] Неверный пароль — сообщение, 5 попыток → временная блокировка.
- [ ] Экран персонажа: 10 точек, скины, выбор работает.
- [ ] После спавна камера плавно появляется, HUD заполнен.
- [ ] В первые 6 секунд урон не проходит (неуязвимость).

## Инвентарь

- [ ] Стартовый набор: 2 тряпки, газировка, нож, карта.
- [ ] ЛКМ выбор, «Надеть» — нож в руках (виден в GTA-слоте).
- [ ] Снятие оружия возвращает его в рюкзак без потери патронов.
- [ ] Использование бинта останавливает кровотечение, HP растёт.
- [ ] Стак: 25 бинтов занимают 3 слота.
- [ ] Перегруз: попытка взять 6 бензопил — «Перегруз», влезает 5.
- [ ] Рюкзак +6 слотов и +5 кг, вес и лимит в HUD меняются.
- [ ] Выброс предмета создаёт маркер на земле, подбор возвращает его.
- [ ] Перекладывание стаков не теряет предметы.

## Выживание

- [ ] Голод/жажда медленно падают, еда/питьё их поднимают.
- [ ] Кровотечение видно в статусе, кровь падает, бинт лечит.
- [ ] Радиация в зоне растёт без маски и падает в противогазе.
- [ ] Ночью/в воде температура падает, HUD показывает < 35 °C и урон.
- [ ] Смерть от голода/жажды/радиации открывает экран смерти.
- [ ] Труп появляется на месте гибели, в нём лежат вещи.

## Зомби

- [ ] В зонах есть зомби разных типов (скины отличаются).
- [ ] Выстрел поднимает зомби в радиусе; они идут к игроку.
- [ ] Удар зомби снимает HP, возможен укус/кровотечение/инфекция.
- [ ] Попадание по зомби даёт хитмаркер, смерть — кровь и лут.
- [ ] Босс появляется в своей зоне, HUD показывает полосу HP.
- [ ] После убийства босса приходит сообщение и топ-лут.
- [ ] Без игроков зомби деспавнятся; лимит 90 не превышается.
- [ ] В безопасном лагере и на базе зомби не атакуют.

## Торговцы и крафт

- [ ] У торговца виден ассортимент и ваш баланс.
- [ ] Покупка списывает деньги и выдаёт предмет; при нехватке денег — отказ.
- [ ] Продажа начисляет ~45% стоимости.
- [ ] Ресток через 10 минут (можно ускорить в конфиге для теста).
- [ ] Крафт бинта из 3 тряпок работает; без материалов — подсказка чего не хватает.
- [ ] Крафт с `bench` требует лагерь/базу.
- [ ] После крафта панель обновляется.

## База

- [ ] Свободная база: «Занять», PIN 4 цифры.
- [ ] Второй игрок без PIN не видит склад.
- [ ] Верный PIN открывает склад; неверный — отказ.
- [ ] Положить/взять предмет, вес склада обновляется.
- [ ] Снятие базы требует пустой склад.
- [ ] После рестарта ресурса владелец, PIN и склад на месте.

## Транспорт

- [ ] Машины заспавнены в 10 точках, заводятся, едут.
- [ ] HUD показывает топливо и скорость, топливо убывает.
- [ ] На нуле двигатель глохнет, канистра заправляет.
- [ ] Ремкомплект чинит кузов рядом с машиной.
- [ ] Взрыв машины → респавн через 90 с.

## PvP и смерть

- [ ] Вне лагеря PvP работает, в лагере — урон блокируется.
- [ ] Килл-фид показывает убийство в чате/CEF.
- [ ] Экран смерти: причина, статистика, таймер, выбор точки.
- [ ] После возрождения инвентарь пуст, стартовый набор выдан.
- [ ] Убитый игрок не может двигаться до возрождения.

## Админ

- [ ] `/dzhelp` показывает список.
- [ ] `/dzgive bandage 5`, `/dzmoney 1000`, `/dzheal` работают под Admin.
- [ ] Без прав — «Недостаточно прав».
- [ ] `/dzsettime 22 30` и `/dzsetweather 11` применяются.
- [ ] `/dzsave` пишет в лог количество профилей.
- [ ] `/dzreloaddata` не ломает текущий раунд.
- [ ] `/dzkick` с причиной работает.

## Производительность

- [ ] `netstat`/монитор: тик сервера не растёт выше ~30% CPU при 10 игроках.
- [ ] Снапшоты 5 Гц не вызывают фризов при 70–90 зомби.
- [ ] CEF открывается < 1 с, панели переключаются без задержек.
- [ ] Утечек нет: после 30 минут количество элементов/маркеров стабильно
      (`/dzstats`).

Если пункт не проходит — сначала смотрите `debugscript 3` на клиенте и консоль
сервера, затем добавляйте шаг в `mta/tests/server_spec.lua`, чтобы поймать регресс.
